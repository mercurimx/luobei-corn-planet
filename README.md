# 萝北玉米星球

移动端优先的互动科普网站。用户扮演一粒刚萌发的玉米种子，自由探索七个区域、收集六张固定记忆卡和一张由最终选择决定的命运卡。

## 本地运行

```bash
pnpm install
pnpm dev
```

构建生产版本：

```bash
pnpm build
```

## 内容与素材

- 区域、卡牌和四种命运的数据集中在 `app/data.ts`。
- 网页图片位于 `public/assets/`，均由开发交接包中的正式源文件转换而来。
- 替换卡面时保持 4:5 比例；不要裁切卡面文字。
- 萝北当地的具体产业事实在正式公开前仍需结合调研资料复核。
- 声音按钮和浏览器授权逻辑已经预留；当前版本在没有正式音频时保持静音可用。

## 状态规则

进度和最终去向存储在浏览器 `localStorage` 中，键名为 `luobei-corn-progress-v1`。清除该键即可重新开始体验。

## 部署

项目使用 Sites 的静态兼容结构，可直接执行生产构建并发布。也可以部署到支持 Vite/Cloudflare Worker 输出的平台。
